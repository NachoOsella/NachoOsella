I like building software where the interesting part is not hidden behind framework magic.

My main stack is **Java + Spring Boot**, usually backed by **PostgreSQL**, with **Angular or React** on the other side of the API. I care about domain rules, explicit boundaries, data integrity, tests, and making projects actually runnable by someone other than me.

Currently studying **Tecnicatura Universitaria en Programación at UTN FRC** and looking for opportunities where I can keep growing as a software developer, especially around backend engineering.

## `~/projects`

### [Dietetica Lembas](https://github.com/NachoOsella/lembas)

> My full-stack thesis project and the largest system I've built so far.

Commercial management platform for a health-food store, combining **inventory, POS, e-commerce, payments, cash registers, suppliers and reporting** around a shared domain.

`Java 21` `Spring Boot` `Angular` `PostgreSQL` `Flyway` `Testcontainers` `Docker`

Some of the problems I'm working on include lot-based stock, FEFO deduction, concurrent inventory updates, branch isolation, unified POS/online orders and idempotent payment flows.

---

### [java-logic-trainer.nvim](https://github.com/NachoOsella/java-logic-trainer.nvim)

> Because apparently opening a browser to practice Java was too much friction.

A **Neovim plugin for learning Java through 187+ exercises**, organized into progressive difficulty levels.

It creates a local Maven workspace, runs deterministic **JUnit 5** checks, supports visible and hidden tests, progressive hints, exercise selection and persistent progress tracking.

`Lua` `Java` `Maven` `JUnit 5` `Neovim`

---

### [Gruvboxitator](https://github.com/NachoOsella/gruvboxitator-web)

> An entirely reasonable consequence of liking Gruvbox too much.

Browser-only image processor that transforms images through an explicit **11-stage pixel pipeline** inspired by Gruvbox Material Dark Hard.

Everything happens locally in the browser: no upload, no backend, no account.

`React` `TypeScript` `Vite` `Canvas API` `Tailwind CSS`

---

### [DotFiles-V4](https://github.com/NachoOsella/DotFiles-V4)

> The rabbit hole.

My reproducible **Arch Linux + Hyprland** environment with a Gruvbox Material Dark Hard visual system and a keyboard-first workflow.

Includes Hyprland, Quickshell, Neovim, Kitty, Fish, Starship, Yazi, Rofi and installation/bootstrap tooling managed around GNU Stow.

`Arch Linux` `Hyprland` `Quickshell` `Neovim` `Fish` `Shell`

---

### [Portfolio](https://github.com/NachoOsella/portfolio)

A Markdown-first personal portfolio with a public site and private content studio.

Projects, articles and pages remain plain Markdown files while a **Spring Boot backend** handles authenticated editing and explicit GitHub backups.

`React` `TypeScript` `Spring Boot` `Java` `Docker` `Caddy`
